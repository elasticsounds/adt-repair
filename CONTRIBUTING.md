# Contributing

Report an issue with the plugin version, operating system, Codex client, ADT Studio/export version if known, page/section IDs, expected behavior and a minimal reproduction. Do not upload a complete textbook, learner responses, reviewer identities or private notes to a public issue. Synthetic or permission-cleared examples are preferred.

Keep repairs for one book in that book's job adapter. Promote a rule into the shared skill only when it reflects a verified integration contract or a demonstrated recurring need. Derive each book's brand and components anew.

Changes should preserve stable IDs, routes and state, record intentional migrations, and test the relevant runtime behavior. A smaller model or shorter prompt is an optimization only if the observable outcome remains acceptable. Record model/token/cost measurements instead of treating forecasts as benchmarks.

Run the Python helper suite, syntax checks, package validation and a fresh-install smoke check for each release. Update the manifest, package version and changelog together. Use version tags so teams can pin a tested release.
